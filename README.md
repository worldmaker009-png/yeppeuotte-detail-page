# 예쁘오뜨 AI 가상 모델 · 상세페이지 스튜디오

마네킹 여성의류 사진 3~10장으로 성인 가상 여성 모델 착용 컷과 한국어 상품 상세페이지를 만드는 웹 도구입니다. GitHub Pages 프런트엔드와 API 키를 보관하는 Cloudflare Workers 백엔드를 분리했습니다.

## 사용

프런트엔드 주소: **https://worldmaker009-png.github.io/yeppeuotte-detail-page/**

Pages가 활성화되고 배포가 성공한 뒤 접속할 수 있습니다. PC 설치 없이 크롬에서 사용합니다.

- **수동 제작:** 사진 1~10장과 상품 정보를 입력하고 **입력 내용으로 상세페이지 만들기**를 누릅니다. AI 키 없이 가능합니다.
- **AI 제작:** 사진 3~10장 → AI 연결 설정 → 전송 동의 → **AI 자동 생성**. 상품명·종류·소개·관찰 색상·디자인 포인트·시각적 조직감·스타일링 제안을 생성하고 미리보기를 만듭니다.
- **가상 모델 + 전체 제작:** **모델 사진 + 상세페이지 AI 제작**을 누르면 원본 사진으로 문구를 분석하고, 정면 모델 컷을 만든 뒤 그 인물을 참조해 측면·3/4 전신·상반신을 순서대로 생성합니다. 1·2·4컷과 스튜디오 배경을 선택할 수 있습니다.
- **원본 비교·검수:** 생성 사진별 **원본 비교**에서 단추·패턴·색상·길이·실루엣을 확인하세요. 상세페이지 사용 여부와 순서를 조정하고 검수 완료를 체크한 뒤 페이지를 다시 만들면 PNG 저장이 가능합니다. 개별 컷 재생성·저장·삭제 및 인물 기준 초기화를 지원합니다.
- **수정:** 모든 상품 문구, 사진 순서, 색상·사이즈·가격·소재 성분·세탁 안내를 직접 편집할 수 있습니다. 편집 후 상세페이지를 다시 만듭니다. **AI 재생성**은 AI 문구를 교체하지만 판매자가 입력한 소재 성분·사이즈·가격·세탁 안내는 유지합니다.
- **AI 표시·비용:** 기본적으로 AI 가상 모델 표시를 PNG에 넣습니다. 상품당 예상 예산과 요청 시도 횟수를 표시하며, 예시 단가는 수정할 수 있습니다. 실제 청구액은 공급자 대시보드에서 확인합니다.
- **저장:** 기본 가로 1720px 또는 860px PNG. 긴 페이지는 높이 12,000px 이하의 여러 이미지로 나눕니다. 다운로드 차단 시 개별 저장 링크를 이용하세요. 디자인 톤은 아이보리·세이지·모노 중 선택합니다.

**실제 백엔드 연결 전에는 'AI API 연결 필요'라고 표시합니다. 가짜 AI 결과나 데모 문구를 AI 결과로 제공하지 않습니다.** 백엔드 설정 확인과 실제 AI 생성 성공도 따로 표시합니다.

## AI 연결·배포

[브라우저만으로 설정하는 단계별 안내, 비용, 보안 및 문제 해결](docs/AI_SETUP.md)을 참고하세요.

- GitHub Pages: 기존 `.github/workflows/deploy-pages.yml` 유지
- Cloudflare Workers: `backend/` 및 수동 실행 워크플로 `.github/workflows/deploy-ai-backend.yml`
- OpenAI API 키: Cloudflare Worker의 **Secret**으로만 저장. 브라우저·GitHub 코드·Pages 변수에 넣지 마세요.
- 공개 백엔드 URL만 GitHub Actions **Variable** `YEPPEUOTTE_AI_API_URL`로 설정하거나 웹 화면의 연결 설정에 입력합니다.
- `public/config.js`에는 공개 URL만 들어갑니다. 관리자 접속 암호는 화면에서 입력하며 영구 저장하지 않습니다.

백엔드 배포, API 키 및 과금 연결은 소유자 계정 설정이 필요합니다. 기본 API는 OpenAI Responses (`gpt-4.1-mini`)와 Images Edits (`gpt-image-1.5`, high, 1024×1536)입니다. 이미지 모델 사용에 추가 조직 인증이 요구될 수 있습니다. 코드 반영만으로 실제 AI 서비스가 연결되지는 않습니다.

## 사진·사실 정보

원본 파일은 수정하지 않고 원래 비율을 유지합니다. AI 사용 시에만 메타데이터를 제거한 축소 JPEG 사본이 백엔드와 OpenAI에 전송됩니다. 분석용 축소본과 달리 상세페이지 렌더링에는 로컬 원본을 사용합니다. 저해상도 원본의 디테일을 새로 복원하지는 않습니다.

소재 성분·혼용률·실측·세탁 방법은 사진으로 추측하지 않습니다. 미입력 시 **판매자 확인 필요** 또는 **제품 라벨 확인 필요**로 표시합니다. AI 관찰과 추천에도 오류가 있을 수 있으므로 게시 전에 검토하세요. 색상은 실제 공식 색상명과 다를 수 있습니다.

동일 인물 참조와 high input fidelity를 사용하지만 얼굴·체형의 완전한 일관성이나 의류 디테일의 정확한 복제를 보장하지 않습니다. 생성 컷은 실제 착용 실측이나 실제 모델 촬영의 증거가 아닙니다. 보이지 않는 디테일은 특히 원본 검수가 필요합니다.

사진은 JPG·PNG·WEBP, 최대 10장, 장당 15MB 및 4천만 화소 이하입니다. 극단적으로 긴 사진은 논리 높이 4,000px 안에서 비율을 유지해 배치합니다. 상품 정보·원본·생성 모델·PNG는 서비스에 영구 저장하지 않습니다. 새로고침하면 입력이 사라지니 먼저 다운로드하세요. AI 제공자의 데이터 처리 정책은 별도 적용됩니다.

## 로컬 개발과 검증

Node.js 24 LTS를 권장합니다. 정적 서버에는 별도 런타임 의존성이 없습니다.

```bash
npm start
# 개발 PC에서 http://localhost:3000
```

```bash
npm ci
npm test
# Chrome/Chromium이 설치된 개발 환경에서:
npm run test:browser
# 필요 시 CHROMIUM_PATH=/실행파일/경로 지정
```

```bash
cd backend
npm ci
npm test
npx wrangler deploy --dry-run
# 로컬 AI 설정: .dev.vars.example을 .dev.vars로 복사해 로컬 값 입력
npx wrangler dev --var ALLOWED_ORIGIN:http://localhost:3000
```

백엔드 로컬 개발에서 웹 연결 주소는 `http://localhost:8787`입니다. localhost HTTP는 로컬 개발에만 허용하며 공개 배포에는 HTTPS가 필수입니다.

테스트는 provider 응답을 **mock**하여 성공·오류 계약을 검사합니다. `npm test`나 브라우저 테스트 통과는 실결제 계정·실사진의 OpenAI 분석 및 모델 이미지 생성 성공이나 품질을 증명하지 않습니다. 실제 연결 검증은 배포 후 사진 3장으로 텍스트와 모델 이미지 생성에 성공하고 원본과 결과의 의류·인물 품질을 검토해야 완료됩니다. 자세한 검증 현황은 [안내 문서](docs/AI_SETUP.md#검증-범위)에 있습니다.

## 파일 구성

- `public/`: 관리자 UI, AI 연결 클라이언트, Canvas 미리보기 및 PNG
- `backend/src/worker.js`: 인증, CORS, 용량·형식 검사, 일일/분당 요청 제한, OpenAI Responses 및 Images Edits API
- `backend/wrangler.toml`: Worker·Durable Object 설정 (비밀값 없음)
- `test/`, `backend/test/`, `scripts/browser-smoke.mjs`: 단위·통합 검증
- `server.js`: 로컬 정적 서버

상품 DB, 쇼핑몰 자동 등록, 사용자별 계정 시스템은 포함하지 않습니다. 공개 프런트엔드는 누구나 열 수 있고, AI 요청에만 관리자 암호가 필요합니다.
